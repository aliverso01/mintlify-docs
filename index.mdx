Documentação **técnica** da Miggo: como os três softwares são construídos, como rodar cada um, como autenticar, quais fluxos atravessam os serviços e a referência completa das APIs, gerada do código.

<Note>
  Procurando como **usar** o produto? A documentação para clientes fica em [ajuda.miggomkt.com.br](https://ajuda.miggomkt.com.br). Aqui o público é quem escreve código.
</Note>

## Os três softwares

<Columns cols={3}>
  <Card title="Plataforma" icon="server" href="/plataforma/rodar-localmente">
    **`backend-miggo`** — Django + DRF. API principal: contas, clientes, agências, posts, calendário editorial, mídia, assinaturas, conversas e webhooks.
  </Card>
  <Card title="Web app" icon="monitor" href="/web/rodar-localmente">
    **`frontend-miggo`** — React 19 + Vite + TypeScript. Interface do cliente (`/app`), das agências e da equipe (`/admin`), incluindo o painel de IA.
  </Card>
  <Card title="MiggoAI" icon="sparkles" href="/miggoai/rodar-localmente">
    **`miggoai_v2/backend`** — Django + DRF. Serviço de IA que gera grid, título, imagem, legenda e hashtags dos posts.
  </Card>
</Columns>
