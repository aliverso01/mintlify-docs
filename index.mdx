Esta é a documentação **de desenvolvimento** da Miggo. Ela descreve como o software é construído: instalação, configuração, arquitetura, modelos de dados, endpoints, funções e deploy dos três repositórios que compõem a plataforma.

<Note>
  Procurando a documentação **de produto** (como usar a plataforma)? Ela fica em [docs.miggomkt.com.br](https://docs.miggomkt.com.br). Aqui o público é quem escreve código.
</Note>

## Os três repositórios

<Columns cols={3}>
  <Card title="Backend" icon="server" href="/backend/instalacao">
    **backend-miggo** — Django + DRF. API principal da plataforma: contas, clientes, posts, calendário editorial, assinaturas, conversas e webhooks.
  </Card>
  <Card title="Frontend" icon="monitor" href="/frontend/instalacao">
    **frontend-miggo** — React 19 + Vite + TypeScript + Tailwind 4. Aplicação web usada por clientes (`/app`) e pela equipe (`/admin`).
  </Card>
  <Card title="MiggoAI" icon="sparkles" href="/miggoai/instalacao">
    **miggoai** — Django + DRF. Serviço de IA que gera título, imagem, legenda e hashtags dos posts.
  </Card>
</Columns>

## Por onde começar

<Steps>
  <Step title="Entenda o todo">
    Leia a [visão geral da arquitetura](/arquitetura/visao-geral) para saber quem chama quem, e os [fluxos principais](/arquitetura/fluxos) para acompanhar um post do nascimento à publicação.
  </Step>
  <Step title="Suba o ambiente">
    Siga o [Quickstart](/quickstart) para ter os três serviços rodando localmente.
  </Step>
  <Step title="Adote as convenções">
    As [convenções de código](/arquitetura/convencoes) valem para os três repos: estilo, migrations, lint, UTF-8, segredos e fluxo de trabalho no Jira.
  </Step>
</Steps>
