Roteiro curto para o ambiente local completo. Cada software tem um guia detalhado; recorra a ele quando travar.

<Warning>
  Nenhum `.env` é versionado. Cada repo traz um `.env.example` com os nomes das variáveis; os valores de desenvolvimento vêm do time. Nunca use chaves de produção na sua máquina.
</Warning>

## Pré-requisitos

| Ferramenta | Para quê |
| --- | --- |
| Python 3 (o mesmo dos `Dockerfile` de cada repo) | Plataforma e MiggoAI |
| Node.js + npm | Web app |
| PostgreSQL | Banco da Plataforma e do MiggoAI (um banco para cada) |
| Redis (opcional) | Só para rodar tarefas em fila com Celery; sem ele as tarefas rodam no próprio processo. Veja [Filas e Celery](/plataforma/filas-e-celery) |

## Portas locais

| Serviço | Porta | Por quê |
| --- | --- | --- |
| Plataforma | `8000` | `runserver` padrão |
| MiggoAI | `8010` | padrão do Web app para o MiggoAI (`src/services/miggoai/config.ts`) |
| Web app | `5173` | padrão do Vite |

## 1. Plataforma

```bash
cd backend-miggo
python -m venv venv
./venv/Scripts/python.exe -m pip install -r requirements.txt   # Linux/macOS: ./venv/bin/python
cp .env.example .env    # preencha conforme /plataforma/configuracao
./venv/Scripts/python.exe manage.py migrate
./venv/Scripts/python.exe manage.py runserver 8000
```

O `.env.example` não traz a `JWT_PRIVATE_KEY`, obrigatória: gere uma chave RSA e acrescente (veja [Rodar a Plataforma localmente](/plataforma/rodar-localmente)). Para a Plataforma falar com o MiggoAI local, defina `MIGGOAI_V2_API_URL=http://localhost:8010` no `.env`. Detalhes em [Rodar a Plataforma localmente](/plataforma/rodar-localmente).

## 2. MiggoAI

```bash
cd miggoai-2.0/miggoai_v2/backend
python -m venv venv
./venv/Scripts/python.exe -m pip install -r requirements.txt
cp .env.example .env    # MIGGO_API_BASE_URL=http://localhost:8000/api/v1/
./venv/Scripts/python.exe manage.py migrate
./venv/Scripts/python.exe manage.py seed_prompts   # sem os prompts, toda geração falha
./venv/Scripts/python.exe manage.py runserver 8010
```

O MiggoAI valida o token da Plataforma com a chave pública `MIGGO_JWT_PUBLIC_KEY`, par da `JWT_PRIVATE_KEY` da Plataforma. Ela é obrigatória e não está no `backend/.env.example`: acrescente-a ao `.env`. Detalhes em [Rodar o MiggoAI localmente](/miggoai/rodar-localmente) e [Autenticação no MiggoAI](/miggoai/autenticacao).

## 3. Web app

```bash
cd frontend-miggo
npm install
cp .env.example .env    # VITE_API_BASE_URL=http://localhost:8000
npm run dev
```

Abra `http://localhost:5173`. Detalhes em [Rodar o Web app localmente](/web/rodar-localmente).

## Verificação

| Serviço | Sinal de saúde |
| --- | --- |
| Plataforma | `curl http://localhost:8000/health/` devolve `200` e `POST /api/v1/account/token/` devolve `access` |
| MiggoAI | `curl http://localhost:8010/health/` devolve `200` |
| Web app | `npm run lint` e `npm run build` sem erros e o login funcionando contra a API local |
