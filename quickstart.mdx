Guia condensado para ter o ambiente local completo. Cada repositório tem uma página de instalação detalhada — use esta como roteiro e recorra a elas quando travar.

<Warning>
  Nenhum arquivo `.env` está versionado. Peça os valores de desenvolvimento a alguém do time; **nunca** commite segredos nem copie chaves de produção para a sua máquina.
</Warning>

## Pré-requisitos

| Ferramenta | Para quê |
| --- | --- |
| Python 3.14 | `backend-miggo` e `miggoai` (o venv do backend vive em `backend-miggo/venv`) |
| Node.js + npm | `frontend-miggo` e o frontend do `miggoai` |
| PostgreSQL 16 | Banco dos dois serviços Django (a imagem usada em compose é `postgres:16`) |
| Git | Clonagem dos repositórios |
| Docker (opcional) | Subir o Postgres sem instalar localmente |

## 1. Backend (`backend-miggo`)

<Steps>
  <Step title="Ambiente virtual e dependências">
    ```bash
    cd backend-miggo
    python -m venv venv
    ./venv/Scripts/python.exe -m pip install -r requirements.txt
    ```
  </Step>
  <Step title="Arquivo .env">
    Crie o `.env` na raiz do repositório. A lista completa de variáveis está em [Configuração do backend](/backend/configuracao); o mínimo para subir é `SECRET_KEY`, `DEBUG`, `ALLOWED_HOSTS` e as `DB_*`.
  </Step>
  <Step title="Banco e migrations">
    ```bash
    ./venv/Scripts/python.exe manage.py migrate
    ./venv/Scripts/python.exe manage.py createsuperuser
    ```
  </Step>
  <Step title="Rodar">
    ```bash
    ./venv/Scripts/python.exe manage.py runserver
    ```
    A API sobe em `http://localhost:8000`. O schema interativo fica em `/api/schema/swagger-ui/`.
  </Step>
</Steps>

## 2. Frontend (`frontend-miggo`)

<Steps>
  <Step title="Dependências">
    ```bash
    cd frontend-miggo
    npm install
    ```
  </Step>
  <Step title="Arquivo .env">
    O frontend lê apenas variáveis prefixadas com `VITE_`. Veja a lista em [Configuração do frontend](/frontend/configuracao) — elas apontam para a API local e para o client ID do Google.
  </Step>
  <Step title="Rodar">
    ```bash
    npm run dev
    ```
  </Step>
</Steps>

## 3. MiggoAI (`miggoai`)

<Steps>
  <Step title="Dependências">
    ```bash
    cd miggoai-2.0/miggoai_v2
    python -m venv backend/venv
    ./backend/venv/Scripts/python.exe -m pip install -r backend/requirements.txt
    ```
  </Step>
  <Step title="Arquivo .env e migrations">
    Consulte [Configuração do MiggoAI](/miggoai/configuracao). Depois:
    ```bash
    cd backend
    ./venv/Scripts/python.exe manage.py migrate
    ./venv/Scripts/python.exe manage.py createsuperuser
    ./venv/Scripts/python.exe manage.py runserver 10000
    ```
  </Step>
  <Step title="Ligar ao backend principal">
    O backend fala com o MiggoAI através de `MIGGOAI_API_URL`, `MIGGOAI_USERNAME` e `MIGGOAI_PASSWORD`, definidas no `.env` do `backend-miggo` (cliente em `app/onboarding/miggoai.py`). Aponte-as para a instância local.
  </Step>
</Steps>
