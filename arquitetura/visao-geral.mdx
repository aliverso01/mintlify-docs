A Miggo é feita de três aplicações independentes, cada uma no seu repositório, que conversam por HTTP.

```mermaid
flowchart TD
    U["Cliente, agência ou equipe Miggo"] --> FE

    subgraph Miggo
        FE["Web app<br/>frontend-miggo<br/>app.miggomkt.com.br"]
        BE["Plataforma<br/>backend-miggo<br/>api.miggomkt.com.br"]
        AI["MiggoAI<br/>miggoai_v2/backend<br/>backend-ai.miggomkt.com.br"]
        DB[("PostgreSQL<br/>plataforma")]
        AIDB[("PostgreSQL<br/>miggoai")]
    end

    FE -->|"REST /api/v1/* · JWT"| BE
    FE -->|"painel de IA no /admin · JWT da Plataforma"| AI
    BE --> DB
    AI --> AIDB

    BE -->|"dispara geração · Api-Key"| AI
    AI -->|"lê clientes e posts, entrega o conteúdo · Api-Key"| BE
    AI -->|"texto e imagem"| OAI["OpenAI"]

    BE --> STR["Stripe / Asaas"]
    BE --> ZER["Zernio"]
    BE --> MC["ManyChat"]

    STR -.->|webhooks| BE
    ZER -.->|webhooks| BE
    MC -.->|webhooks| BE
```

## Responsabilidade de cada software

  </Card>
  <Card title="MiggoAI" icon="sparkles" href="/miggoai/arquitetura">

## Contratos entre os serviços

| De → para | Como autentica | Para quê | Onde ler |
| --- | --- | --- | --- |
| Web app → Plataforma | `Authorization: Bearer <access>` (JWT RS256 emitido em `POST /api/v1/account/token/`) | toda a API `/api/v1/*` | [Autenticação na Plataforma](/plataforma/autenticacao) |
| Web app → MiggoAI | o mesmo JWT da Plataforma | painel de IA: prompts, execuções, custos, geração manual | [Painel de IA](/web/painel-de-ia) |
| Plataforma → MiggoAI | `Authorization: Api-Key <MIGGOAI_V2_API_KEY>` | grid do onboarding, gerar agora, gerar card, regenerar item, peças de perfil | [Integração com a Plataforma](/miggoai/integracao-com-a-plataforma) |
| MiggoAI → Plataforma | `Authorization: Api-Key <MIGGO_API_KEY>` | ler clientes, calendário e posts; entregar mídia e conteúdo | [Integração com a Plataforma](/miggoai/integracao-com-a-plataforma) |
| Provedores → Plataforma | assinatura ou token por provedor | cobrança, publicação, conexão de contas, WhatsApp | [Webhooks](/plataforma/guias/webhooks) |

Toda chamada da Plataforma a um serviço externo, MiggoAI incluído, é registrada na tabela `Integration` (app [`integration`](/plataforma/apps/integration)). O registro é *best-effort*: falhar ao auditar nunca derruba o fluxo.

## API da Plataforma

Os recursos ficam sob `/api/v1/`, um prefixo por app Django (`/api/v1/account/`, `/api/v1/client/`, `/api/v1/agency/`, `/api/v1/post/`…). Os webhooks ficam fora do prefixo, em `/webhooks/`. A lista completa de endpoints, agrupada por recurso, está na [Referência de API da Plataforma](/plataforma/api-referencia); o mapa de apps está em [Estrutura da Plataforma](/plataforma/estrutura).
