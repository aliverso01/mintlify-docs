O app usa cinco React Contexts. A árvore de providers é montada em dois pontos: os globais (toda a app) em `src/main.tsx`, e os de layout (só dentro da área autenticada) em `src/layout/AppLayout.tsx`.

```
main.tsx
└── ThemeProvider
    └── AuthProvider
        └── MarcaProvider
            └── AppWrapper (HelmetProvider)
                └── App
                    └── ... (dentro de AppLayout, nas rotas autenticadas)
                        └── SidebarProvider
                            └── SearchProvider
                                └── LayoutContent
```

## `ThemeContext` (`src/context/ThemeContext.tsx`)

- **Guarda**: `theme: "light" | "dark"`.
- **Shape do value** (`ThemeContext.tsx:8-11`):
  ```ts
  type ThemeContextType = { theme: Theme; toggleTheme: () => void };
  ```
- **Persistência**: lê/grava `theme` em `localStorage` (`ThemeContext.tsx:23,32`) e alterna a classe `dark` em `document.documentElement` (`ThemeContext.tsx:33-37`), que é o gatilho para o `@custom-variant dark` do Tailwind (ver `layout-e-tema.mdx`).
- **Hook de consumo**: `useTheme()` (`ThemeContext.tsx:52-58`), lança erro se usado fora do provider.
- **Montado em**: `src/main.tsx:22` — envolve toda a aplicação (nível mais externo).

## `MarcaContext` (`src/context/MarcaContext.tsx`)

- **Guarda**: `marca: MarcaApi | null` (marca da agência; `null` = marca Miggo) e `nome` (o da agência ou "Miggo").
- **Carga**: `fetchMarca()` (`src/utils/marca.ts`) antes das rotas, com splash neutro, e de novo a cada troca de usuário (login, logout, troca de conta). O backend resolve a marca pelo usuário logado ou, anônimo, pelo host (`X-Miggo-Host`). `applyMarca`/`clearMarca` aplicam a paleta; só no host Miggo carrega o Google Analytics (MIG-517).
- **Hook de consumo**: `useMarca()`; o logo sai de `MarcaLogo` (`src/components/common/MarcaLogo.tsx`).
- **Montado em**: `src/main.tsx`, dentro de `AuthProvider` (lê `useAuthContext()`), envolvendo `AppWrapper`/`App`.

O antigo `PreviewContext` (preview mode, "visualizar como cliente") foi removido.

## `AuthContext` (`src/context/AuthContext.tsx`)

- **Guarda**: `user`, `loading`, `error` + as operações de conta. Detalhado por completo em `autenticacao.mdx`.
- **Hook de consumo**: `useAuthContext()` (`AuthContext.tsx:414-420`) — a maioria das telas usa o wrapper `useAuth()` (`src/hooks/authHook.ts`), que adiciona navegação.
- **Montado em**: `src/main.tsx`, logo abaixo de `ThemeProvider`; envolve `MarcaProvider`.

## `SearchContext` (`src/context/SearchContext.tsx`)

- **Guarda**: `searchQuery: string`.
- **Shape do value** (`SearchContext.tsx:3-6`):
  ```ts
  interface SearchContextType { searchQuery: string; setSearchQuery: (query: string) => void; }
  ```
- **Hook de consumo**: `useSearch()` (`SearchContext.tsx:20-26`).
- **Montado em**: `src/layout/AppLayout.tsx:88` — dentro de `SidebarProvider`, só envolve o conteúdo do layout autenticado (`LayoutContent`).

## `SidebarContext` (`src/context/SidebarContext.tsx`)

- **Guarda**: `isExpanded`, `isMobileOpen`, `isHovered`, `activeItem`, `openSubmenu` (`SidebarContext.tsx:3-14`).
- **Shape do value** (`SidebarContext.tsx:3-14`):
  ```ts
  type SidebarContextType = {
    isExpanded: boolean; isMobileOpen: boolean; isHovered: boolean;
    activeItem: string | null; openSubmenu: string | null;
    toggleSidebar: () => void; toggleMobileSidebar: () => void;
    setIsHovered: (isHovered: boolean) => void;
    setActiveItem: (item: string | null) => void; toggleSubmenu: (item: string) => void;
  };
  ```
- **Responsividade embutida**: escuta `resize` e força `isMobileOpen = false` acima de 768px; `isExpanded` reportado no value é sempre `false` em telas mobile, independente do estado interno (`SidebarContext.tsx:36-51,68`).
- **Hook de consumo**: `useSidebar()` (`SidebarContext.tsx:18-24`).
- **Montado em**: `src/layout/AppLayout.tsx:87` — nível mais externo dentro de `AppLayout`, envolve `SearchProvider`.

## Resumo — onde cada contexto é montado

| Contexto | Montado em | Escopo |
|---|---|---|
| `ThemeContext` | `main.tsx` | App inteira (inclusive telas públicas) |
| `AuthContext` | `main.tsx` | App inteira |
| `MarcaContext` | `main.tsx` | App inteira (inclusive telas públicas, pelo host) |
| `SidebarContext` | `layout/AppLayout.tsx` | Só dentro da área autenticada (após os guards) |
| `SearchContext` | `layout/AppLayout.tsx` | Só dentro da área autenticada |
