Fonte: `src/App.tsx`. As telas ficam em `src/pages/<Pasta>/`. Como as áreas funcionam está em [Roteamento e áreas](/web/roteamento).

## Uma tela, várias áreas

A maioria das telas de operação é montada em mais de uma área com **o mesmo componente**. O componente de rota é um container que escolhe a visão pelo papel do usuário. Exemplos: `Dashboard/Home` renderiza `DashboardAdmin` ou `DashboardClient`; `Content/ContentKanban`, `Agenda/AgendaSugestao` e `Brandkit/BrandkitPage` seguem o mesmo padrão. Por isso nenhum componente escreve o prefixo da área à mão (use `useRoleArea().path()`).

## Rotas públicas e de fluxo

| Rota | Tela | Acesso |
|---|---|---|
| `/signin` | `AuthPages/SignIn` | Pública. Com sessão, volta para o `?next=` (só caminho interno) ou para `/`. |
| `/signup` | redireciona para `/onboarding` | Pública |
| `/reset-password` | `AuthPages/ResetPassword` | Pública |
| `/onboarding` | `Onboarding/OnboardingShell` | Pública (a etapa 1 cria a conta). Veja [Onboarding no Web app](/web/onboarding). |
| `/midia/:token` | `Media/MediaDownloadPage` | Pública. Quem autoriza é o token assinado do link enviado por WhatsApp. |
| `/terms`, `/privacy` | `Legal/TermsOfUse`, `Legal/PrivacyPolicy` | Pública |
| `/grid/aprovar` | `Grid/GridApprovalPage` | Login, fora dos guards de onboarding e assinatura (aprovação do grid por link). |
| `/onboarding/conectado/:platform/:clientId/*` | `Onboarding/SocialConnected` | Login. Retorno do OAuth de rede social iniciado no onboarding. |
| `/` | `RoleHomeRedirect` | Login. Manda para a home da área. |
| `*` | `OtherPage/NotFound` | — |

## Operação de conteúdo (`/admin`, `/agency` e `/app`)

Mesmos subcaminhos nas três áreas. No `/admin` e no `/agency` a tela exige o módulo indicado; no `/app` não há módulo.

| Subcaminho | Tela | Módulo (`/admin`, `/agency`) |
|---|---|---|
| (index) | `Dashboard/Home` no `/admin` e `/app`; `Agencia/AgenciaHome` no `/agency` | — |
| `analytics` | `Dashboard/AnalyticsDashboard` | — |
| `profile` | `UserProfiles` | — |
| `content` | `Content/ContentKanban` | `conteudo` |
| `content/parados` | `Content/StalledPosts` (fila de posts parados) | `conteudo`; não existe no `/app` |
| `editorial-calendar` | `EditorialCalendar/EditorialCalendar` | `conteudo` |
| `agenda/sugestao` | `Agenda/AgendaSugestao` | `conteudo` |
| `media-library` | `Media/MediaLibrary` | `conteudo` |
| `brandkit` | `Brandkit/BrandkitPage` | `conteudo` |
| `briefing` | `Briefing/Briefing` | `clientes` |
| `social-networks` | `SocialNetworks/SocialNetworksPage` | `clientes` |
| `history` | `History/HistoryList` | — |
| `notifications` | `Admin/NotificationHistory` | — |
| `clients` | `Clients/ClientsList` | `clientes`; não existe no `/app` |
