Base: `backend/core/urls.py:10-18`. Todas as rotas abaixo são prefixadas por `/api/`. Exceto os endpoints de token, **toda view exige autenticação JWT** (`REST_FRAMEWORK.DEFAULT_PERMISSION_CLASSES = IsAuthenticated`, `backend/core/settings.py:109-111`) — envie `Authorization: Bearer <access_token>`.

## Autenticação

| Método | Rota | View |
|---|---|---|
| POST | `/api/token/` | `TokenObtainPairView` (SimpleJWT) |
| POST | `/api/token/refresh/` | `TokenRefreshView` (SimpleJWT) |

<ParamField path="username" type="string" required>Usuário Django.</ParamField>
<ParamField path="password" type="string" required>Senha.</ParamField>

<ResponseField name="access" type="string">Access token JWT (expira em 30 min).</ResponseField>
<ResponseField name="refresh" type="string">Refresh token JWT (expira em 7 dias).</ResponseField>

`/api/token/refresh/` recebe `{"refresh": "<token>"}` e devolve `{"access": "<novo token>"}`.

<Accordion title="apps.clients — /api/clients/">

Fonte: `backend/apps/clients/urls.py`, `backend/apps/clients/views.py`.

| Método | Rota | View | Descrição |
|---|---|---|---|
| GET | `/api/clients/` | `ClientListView` | Lista clientes do backend-miggo. |
| GET | `/api/clients/<int:client_id>/` | `ClientDetailView` | Detalhe do cliente + briefing embutido. |
| GET | `/api/clients/<int:client_id>/variables/` | `ClientVariablesView` | Variáveis de prompt já salvas para o cliente. |

**GET `/api/clients/`**
<ParamField path="search" type="string">Busca livre (query param), repassada ao backend-miggo.</ParamField>
<ResponseField name="[]" type="array">Lista crua de clientes conforme devolvida pelo backend-miggo (`client/list/`).</ResponseField>

**GET `/api/clients/<client_id>/`**
<ResponseField name="briefing" type="object">Dict `{key: value}` do client-meta, anexado ao objeto do cliente (`views.py:20-33`).</ResponseField>
<ResponseField name="error" type="string">`"Cliente não encontrado."`, status 404, se o backend-miggo não devolver nenhum resultado.</ResponseField>

**GET `/api/clients/<client_id>/variables/`**
<ResponseField name="[]" type="array">Lista de `{key, value}` — respostas de variável já fornecidas antes por este cliente, excluindo chaves voláteis (`views.py:36-43`).</ResponseField>

Qualquer falha de comunicação com o backend-miggo devolve `{"error": "<mensagem>"}` com o status HTTP repassado (ou `502` se o backend-miggo não informou status).

</Accordion>

<Accordion title="apps.prompts — /api/prompts/">

Fonte: `backend/apps/prompts/urls.py`, `backend/apps/prompts/views.py`.

| Método | Rota | View | Descrição |
|---|---|---|---|
| GET | `/api/prompts/workflows/` | `WorkflowListView` | Lista workflows ativos (com config aninhada). |
| GET | `/api/prompts/` | `PromptListCreateView` | Lista prompts (`?workflow=<key>`). |
| POST | `/api/prompts/` | `PromptListCreateView` | Cria um novo `PromptDefinition`. |
| GET | `/api/prompts/<int:pk>/` | `PromptDetailView` | Detalhe de um prompt. |
| PUT | `/api/prompts/<int:pk>/` | `PromptDetailView` | Atualiza um prompt (versiona se `content` mudar). |
| DELETE | `/api/prompts/<int:pk>/` | `PromptDetailView` | Remove um prompt. |
| GET | `/api/prompts/<int:pk>/versions/` | `PromptVersionsView` | Histórico de versões do prompt. |
| POST | `/api/prompts/<int:pk>/activate/` | `PromptActivateView` | Ativa o prompt. |
| POST | `/api/prompts/<int:pk>/deactivate/` | `PromptDeactivateView` | Desativa o prompt. |
| GET | `/api/prompts/<int:pk>/variables/` | `PromptVariableListCreateView` | Lista variáveis do prompt. |
| POST | `/api/prompts/<int:pk>/variables/` | `PromptVariableListCreateView` | Cria variável no prompt. |
| PUT | `/api/prompts/variables/<int:pk>/` | `PromptVariableDetailView` | Atualiza uma variável. |
| DELETE | `/api/prompts/variables/<int:pk>/` | `PromptVariableDetailView` | Remove uma variável. |
| POST | `/api/prompts/<int:pk>/detect-variables/` | `DetectVariablesView` | Compara `{{chaves}}` do conteúdo com as `PromptVariable` cadastradas. |
| POST | `/api/prompts/<int:pk>/preview/` | `PromptPreviewView` | Renderiza o prompt com valores enviados — nunca chama IA. |

**PUT `/api/prompts/<pk>/`**
<ParamField path="content" type="string">Novo conteúdo do template. Se diferente do atual, cria uma `PromptVersion` com o conteúdo ANTERIOR antes de salvar (`views.py:49-67`).</ParamField>
<ParamField path="change_note" type="string">Nota de mudança, salva na versão criada.</ParamField>
<ResponseField name="current_version" type="integer">Incrementado automaticamente quando `content` muda.</ResponseField>

**POST `/api/prompts/<pk>/detect-variables/`**
<ResponseField name="new" type="array">Chaves `{{...}}` no template que ainda não têm `PromptVariable` cadastrada.</ResponseField>
<ResponseField name="removed" type="array">`PromptVariable` cadastradas que não aparecem mais no template.</ResponseField>
<ResponseField name="unchanged" type="array">Chaves presentes nos dois lados.</ResponseField>

**POST `/api/prompts/<pk>/preview/`**
<ParamField path="values" type="object">Dict `{chave: valor}` para renderizar o template.</ParamField>
<ResponseField name="rendered" type="string">Template com as variáveis substituídas.</ResponseField>
<ResponseField name="structural" type="string">Bloco de formato de saída (JSON schema instruction) que o sistema anexa na hora da geração real — não editável, mas exibido para contexto (`output_contract.instruction_for_slug`).</ResponseField>

</Accordion>

**POST `/api/generations/{test,production}/`**
<ParamField path="workflow_key" type="string" required>`title`, `image`, `caption` ou `hashtags`.</ParamField>
<ParamField path="client_id" type="integer" required>Id do cliente no backend-miggo.</ParamField>
<ParamField path="post_id" type="integer" required>Id do post (card) no backend-miggo.</ParamField>

**POST `/api/generations/{test,production}/complete/`**
<ParamField path="client_id" type="integer" required />
<ParamField path="post_id" type="integer" required />

<ResponseField name="[]" type="array">Lista de 1 a 4 objetos `Generation` (título, imagem, legenda, hashtags, na ordem — a cadeia para no primeiro que falhar).</ResponseField>

**GET `/api/generations/context/`**
<ParamField path="client_id" type="integer" required />
