## `src/services/subscriptionSync.ts`

Sincronização assíncrona (job em background) de assinaturas/faturas.

```ts
export async function runSubscriptionSyncAsync(options?: {
  clientId?: number | string | null;
  onStatus?: (status: "PENDING" | "RUNNING" | "DONE" | "FAILED") => void;
  intervalMs?: number;   // default 2000
  timeoutMs?: number;    // default 300000
}): Promise<SyncResult>;
```

Fluxo (`subscriptionSync.ts:42-90`):
1. `POST /api/v1/subscription/sync-subscription-status-invoices/async/` com `{ client_id }` (se informado) → recebe `{ job_id, status }`.
2. Faz polling em `GET /api/v1/subscription/sync-subscription-status-invoices/status/<job_id>/` a cada `intervalMs`, chamando `onStatus` a cada mudança, até `status === 'DONE'` (resolve com `result`) ou `'FAILED'` (lança erro) ou estourar `timeoutMs` (lança erro de timeout).
